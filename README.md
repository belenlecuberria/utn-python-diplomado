# Diplomatura Dominando Python — UTN-FRD

Repositorio de ejercicios, apuntes y proyectos de la **Diplomatura Dominando Python: de Básico a Avanzado para Inteligencia Artificial** (Universidad Tecnológica Nacional — Facultad Regional Delta).

> 🎯 **Objetivo a largo plazo:** alcanzar competencias sólidas en Machine Learning combinando esta diplomatura con un plan personal de programación complementario (Git, buenas prácticas, agéntica, portfolio).

---
